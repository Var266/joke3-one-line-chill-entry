## The entry

A single sentence of horror, under 200 characters, written by `main.ts` to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The program validates the line before writing it: exactly one sentence, 1–200 characters, a single line with no surrounding whitespace.
